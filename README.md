#  Sistema de Assistência Técnica de Celulares

Sistema web desenvolvido para auxiliar no gerenciamento de uma assistência técnica de celulares, facilitando a organização e o controle das informações de clientes, usuários e aparelhos.

##  Sobre o Projeto

O sistema tem como finalidade otimizar o atendimento e o gerenciamento de uma assistência técnica, centralizando os dados em uma única aplicação. Por meio dele, é possível realizar a autenticação de usuários, consultar clientes cadastrados e associar aparelhos celulares aos seus respectivos proprietários.

O projeto foi desenvolvido utilizando Python com Flask e banco de dados MySQL, aplicando conceitos de desenvolvimento web, integração com banco de dados e gerenciamento de informações.

##  Funcionalidades

- Login e autenticação de usuários.
- Exibição do nome do usuário conectado.
- Consulta e busca de clientes.
- Associação de clientes aos aparelhos celulares.
- Logout para encerrar a sessão.

##  Tecnologias Utilizadas

- **Python:** linguagem de programação.
- **Flask:** framework para desenvolvimento web.
- **MySQL:** gerenciamento do banco de dados.
- **HTML5 e CSS3:** estruturação e estilização das páginas.
- **MySQL Workbench:** criação e gerenciamento do banco de dados.

##  Como Executar

1. Instale as dependências:

```bash
pip install -r requirements.txt
```

2. Configure a conexão com o banco de dados MySQL.
3. Execute a aplicação:

```bash
python app.py
```

4. Acesse pelo navegador:

```text
http://127.0.0.1:5000/
```

##  Banco de Dados

O banco de dados organiza as informações em três entidades principais:

- **Usuários:** armazenam os dados de acesso ao sistema.
- **Clientes:** armazenam informações pessoais e de contato.
- **Aparelhos:** registram os dados dos celulares e seus respectivos proprietários.
